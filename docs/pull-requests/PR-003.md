# PR-003: Hero banner and Joey Club teaser

**Branch:** `feature/hero-teaser` → `main` (merged `--no-ff`)
**Stories:** HB-01, HB-02, HB-03 (hero), TS-01, TS-02 (teaser), DL-01 (teaser click)

## Why

The page needs one `h1` with an introduction, an accessible image and in-page navigation, plus a Joey Club promotion that is safe to open in a new tab and visible to analytics.

## What changed

- **Hero (`airline/components/hero`).**
  - Model: `HeroBanner`, `HeroImage` and `JumpLink` interfaces (models package now `2.0.0`), implemented by `HeroBannerImpl`.
  - Alt text: the author's alt, then the asset's `dc:description`, never `dc:title`. With no alt, publish hides the image and edit mode shows a warning.
  - `srcset` uses only the 640/960/1280 web renditions, never the original. `src` is the 960 rendition, and `width`/`height` come from the aspect ratio.
  - Jump-link anchors are normalised to `[a-z0-9_-]`, so a value such as `javascript:` can only ever become a harmless fragment.
  - HTL: `<section>` containing `h1`, intro and `<nav aria-labelledby>`. The image loads with `loading="eager" fetchpriority="high"`.
  - Dialog: Content, Image and On this page tabs. The edit config adds an image drop target.
  - The template structure places the hero, unlocked, before `content` (ADR-020). Its component group is hidden, so authors can't add a second one.
- **Teaser (`airline/components/teaser`, ADR-003).**
  - `TeaserImpl` delegates to Core Teaser v2 through `@Via(ResourceSuperType)`. `RelSafeLink` and `RelSafeListItem` add `rel="noopener noreferrer"` once for `target="_blank"`.
  - The exported type and data-layer `@type` report `airline/components/teaser`.
  - The Core HTL is unchanged.
- **Frontend.**
  - `teaser.ts` uses a delegated listener to push `airline:teaser:click`.
  - New hero and teaser styles, plus header, footer and main layout.
  - The archetype's dark-mode and language-navigation styles are removed. The palette meets WCAG AA contrast, focus is shown with `:focus-visible`, and reduced motion is respected.
- **Sample content.**
  - `family-hero.jpg` and `joey-club.jpg`: AI-generated for this exercise, with no brands or logos, shipped with `dc:description` and pre-built renditions (`scripts/prepare-sample-images.ps1`).
  - New `flying-infants-children` page with hero and teaser, and a hero on the home page.
- **Test fixes.**
  - Removed `junit-addons`: its old Xerces broke AEM Mocks asset creation.
  - Excluded `commons-lang3` 3.1 from `slf4j-test`: it shadowed the SDK copy that Core Teaser needs.

## Risks

- **Dead jump link until PR-004.** The `#booking-infants` link points at the travel-questions section that PR-004 adds.
