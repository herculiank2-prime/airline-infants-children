# PR-005: Playwright and axe UI tests, publish deployment

**Branch:** `feature/ui-tests` to `main` (merged `--no-ff`)
**Stories:** PT-02 (accessibility), EN-04 (responsive), EN-06 (no console errors), AC-01, DL-01, SE-01, SE-02, HD-02

## Why

The archetype's Cypress module only checks that AEM logs in. The design (section 9, ADR-012) calls for browser tests on publish at mobile and desktop widths, with automated WCAG checks.

## What changed

- **Replaced Cypress with Playwright** in `ui.tests/test-module`: `@playwright/test` 1.65.1, `@axe-core/playwright` 4.14.1 and TypeScript. `npm run lint` runs `tsc --noEmit`.
- **Two projects**, `mobile-375` and `desktop-1280`. Locally they use the installed Edge, so no browser download is needed. In the Cloud Manager image (`mcr.microsoft.com/playwright:v1.65.1-noble`), `PW_CHANNEL=""` switches them to the bundled Chromium.
- **Specs** (15 tests per project, 30 in total):
  - `accordion.spec.ts`: heading, the six questions in order, collapsed ARIA state, keyboard (Tab, Enter, Space), find-in-page and the hero jump link.
  - `datalayer.spec.ts`: expand and collapse events, item IDs in the data-layer state, and the Joey Club teaser click.
  - `accessibility.spec.ts`: axe WCAG 2.1 AA with panels collapsed and expanded, landmarks, a single h1, the skip link, no horizontal scroll, eager hero, lazy images and no console errors.
  - `structured-data.spec.ts`: a single FAQPage that matches the accordion, title, description, canonical, and the persisted-query contract with its cache headers.
- **Maven**: Node 24.22.3 and npm 11.19.1, `npm ci` with `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`. The artifact is renamed to `...ui.playwright.tests`.
- **`.gitattributes`**: `*.sh` and `Dockerfile` are checked out with LF line endings, so `run.sh` runs in Linux containers.
- **Publish**: fresh 4503 (ADR-025), deployed with `-PautoInstallSinglePackagePublish`, with the airline paths tree-activated from author.
- **ADRs** 025 (publish reset), 026 (test policy for short URLs) and 027 (canonical deviation).

## Verification

- `mvn clean install -PautoInstallSinglePackagePublish`: BUILD SUCCESS.
- Publish: the demo and component-states pages return 200. The demo page has 6 accordion buttons and one FAQPage block. `travel-questions-by-folder` returns 6 items in order with `Cache-Control: max-age=60, public, s-maxage=150, stale-while-revalidate=30, stale-if-error=86400`.
- `npm test` against 4503: 30 passed.

## Test fixes made while running against publish

- Without a Dispatcher, the short-URL image 404 is expected and is now skipped (ADR-026).
- The title expectation had a site suffix that the design does not specify.
- A `hidden="until-found"` panel keeps its box in the layout, so the test asserts that the panel's content is hidden.
- The canonical link is root-relative (ADR-027).
