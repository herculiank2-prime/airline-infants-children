# PR-007: Match the live reference page (content, header, footer and styling)

**Branch:** `feature/live-site-parity` (from `feature/docs`) to `main`
**Stories:** AC-01, DL-01, SE-01, PF-01, PT-02, EN-06
**Decision:** ADR-029 (supersedes assumption A-02 for the sample content)

## Why

A review against the reference page ([qantas.com, Flying with infants and children](https://www.qantas.com/en-au/travel-information/flying-infants-children)) found that the demo looked nothing like it. The project owner gave permission to reuse the page's copy, images and visual design, so this PR brings the local page to visual and content parity.

## What changed

### Content (`ui.content.sample`)

- **Demo page** rebuilt in the live order:
  - hero with the live intro and 11 "On this page" jump links
  - information alert
  - six image-and-text teasers (Qantas and Bluey, Joey Club, inflight entertainment, meals, children travelling alone, support for children with additional needs)
  - booking section, with the accordion in a full-width grey band
  - child fares, bassinets and car seats, baggage, inflight comfort devices (two-column seat diagrams), boarding and security cards, related information
- **Six question fragments** carry the live answers. Relative links point to qantas.com, and each fragment's description notes the source.
- **Nine DAM images** replace the placeholder hero and Joey Club images. Each keeps the live alt text.
- **Header experience fragment**: Qantas and oneworld logos, main navigation, Manage booking and a Log in button.
- **Footer experience fragment**: back to top, logo, link rows, ABN and the Acknowledgement of Country.
- The `travel-information` parent page no longer redirects, so the breadcrumb shows the right trail.

### Structure and policies (`ui.content`, `ui.apps`)

- New **breadcrumb** proxy component (Core Breadcrumb v3), added to the template structure above the hero.
- **Section container** policy with Style System options for a grey band and a two-column layout.
- **Content text** policy with styles for alert, card, related links, section intro and card icons (airport, baby bottle).
- Teaser policy gains image-left, image-right and stacked styles, and lets authors pick the title level.
- `travelquestions` HTL renders `aria-labelledby` only when the component has its own heading. Without this, the section pointed at a missing ID.

### Styling (`ui.frontend`)

- Theme variables matching the live page: colours, type scale, 1232 px content width, gutters and the chevron link style.
- Rewritten styles for the header, footer, hero, teasers, text styles, sections, breadcrumb and accordion.
- The grey band spans the full viewport while its content stays aligned with the page column, and nothing scrolls horizontally.
- Card icons and the footer logo are CSS backgrounds, because the rich-text sanitizer strips `loading="lazy"` (PF-01).

### Tests and docs

- UI tests updated for the live titles (curly apostrophe), the `infant-questions` data-layer parent, the `#booking` jump link, the qantas.com Joey Club URL and answers that start with a list.
- ADR-029. `AGENTS.md` ground rule and assumption A-02 updated.

## Known gaps

- The header's sub-menus and some footer link targets are approximations, because the live header and footer are rendered by JavaScript.
- The "Qantas Sans" web font isn't bundled; the stack falls back to Helvetica or Arial.
- The sample package uses FileVault `merge` mode. On an instance that already has the old demo content, delete the page, fragments and experience fragments before reinstalling (see `docs/05-build-deploy-test.md`).
