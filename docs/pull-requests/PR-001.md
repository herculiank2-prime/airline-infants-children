# PR-001 — Analysis, solution design and architect review

**Branch:** `feature/analysis-design` → `main` (merged `--no-ff`)
**Type:** documentation and design tooling. No production code.

## Why

Part A of the exercise asks for an architecture someone else can build from. This PR fixes the requirements, design and decisions before any component work starts, so later PRs can be reviewed against them.

- `docs/01-analysis-discovery.md`: requirements trace, assumptions, open questions, reuse inventory, environment findings.
